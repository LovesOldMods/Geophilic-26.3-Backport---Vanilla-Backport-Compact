🍂 About: 

I know there's already a backport that has the Pale Garden update however this one brings a lot of the newer Geophilic stuff over to 1.21.1. Most of it is plants and little details, but a lot of biomes got touched, and they feel so much more alive than before! Feedback is still very welcome! There could be a few bugs that I haven’t found while playtesting, so feel free to report those as well!

These are the changes when compared to the old version:

Forests and Dark Forests are now covered in leaf litter, so the ground doesn’t look so bare anymore. Regular forests also get small bushes scattered around.

Birch Forests and Old Growth Birch Forests now have wildflowers growing all over, and the old growth ones have them even denser. Both get bushes too.

Meadows are now full of wildflowers.

Plains and all the Windswept biomes now have small bushes.

Rivers and Swamps now have firefly bushes. In swamps they like to grow near the water, which looks really nice at night.

Wooded Badlands get dry grass, leaf litter under the trees, and the odd firefly bush.

Fallen trees for every wood type were updated to match the newer versions.

The Pale Garden is reworked and it has way more tree shapes now, with crooked, slim and large pale oaks, plus trees that grow with a creaking heart inside. There are also patches of pale moss, dead bushes, fallen pale oak logs and stumps, and eyeblossoms spread around. Sugar cane and pumpkins can show up too.

Please report any issues if you find something weird on the github that is linked! Please do not bother the original developers with any issues that you find after installing this mod.

💻Mod Requirements:
You’ll need Geophilic and VanillaBackport (with Platform API) for this to work, and Fabric API if you’re on Fabric. It works on both Fabric and NeoForge. If you have any suggestions on what else I could bring over from the newer versions, do leave a comment!
